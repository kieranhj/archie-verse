RasterMan inspired demo OS?
~~~
Requirements:
- Can run arbitrary blocking operations e.g. disk load, code gen, image gen, decompression
  in the background, using spare cycles across many frames.
- Don't have to write special handling within the tasks themselves (i.e. poll & yield).
- Demo effects are guaranteed to continue to update at 50Hz.

Already achieve this on the Beeb:
- Hang everything off a 50Hz IRQ timer - update logic, render screen, play music in IRQ.
- When IRQ returns it gives remaining cycles back to the original running exe.
- Simple task system for calling arbitrary functions on main exe thread.

Sarah's Vertex Transform code
~~~
9 muls/vert, full 3x3 matrix rotation.
Push results on the stack.
Combine vertex count w/ source ptr as a temporary.
Pre-shift vertex precision.
Pre-shift matrix precision.

transform_loop:
	LDMIA r12!, {r9, r10} ;x, y
	ORR r12, r14, r12, LSL #11

	;r0-r8 - matrix
	;r9, r10 - x, y
	;r11 - temp
	;r12 - source ptr
	;r14 - temp

	MUL r11, r9, r6   ;z=x*m20 + y*m21
	MLA r11, r10, r7, r11

	MUL r14, r10, r1  ;x = y*m01

	MUL r10, r4, r10     ;y = y*m11
	MLA r10, r3, r9, r10 ;y = x*m00 + y*m11

	MLA r9, r0, r9, r14 ;x = x*m00 + y*m01

	MOV r14, r12, LSR #11
	LDR r14, [r14]  ;z
	ADD r12, r12, #4<<11

	MLA r9, r2, r14, r9   ;x = x*m00 + y*m01 + z*m02
	MLA r10, r5, r14, r10 ;y = x*m01 + y*m11 + z*m12
	MLA r11, r8, r14, r11 ;z = x*m02 + y*m21 + z*m22	

	MOV r14, r12, LSL #(32-11)
	MOV r14, r14, LSR #(32-11)
	MOV r12, r12, LSR #11

	MOV r9, r9, ASR #12
	MOV r10, r10, ASR #12
	MOV r11, r11, ASR #12
	STMDB sp!, {r9, r10, r11}


	SUBS r14, r14, #1
	BNE transform_loop
